How to enable network-wide blocking

  1. Open AdBlockAll, tap Enable in the Network-Wide Blocking section.
  2. Allow the system prompt to add the DNS configuration.
  3. If iOS reports a permission error on the first attempt, delete the app, reinstall it, restart the device, then try again — this is an OS-level quirk, not an app defect.

How to enable Safari blocking

  1. Open AdBlockAll and tap How to Enable in the Safari section.
  2. Settings → Apps → Safari → Extensions → Content Blockers.
  3. Turn on AdBlockAll.

This is a one-time manual step required by iOS. No app can toggle it programmatically.

Why does the block counter stay at 0?

  • Safari blocking is not counted. It is performed by iOS itself and apps cannot see its statistics. Ads may well be blocked in Safari while the counter stays unchanged.
  • Only network-wide blocking hits are counted. Enable it, then browse for a while and check again.
  • If the counter is still 0, open the statistics screen and run Storage Self-Test. The App Group must read “available” and subscription-domains.txt must be listed. If the file is missing, return to the main screen and tap Update Subscription.

What cannot be blocked

Blocking works at the domain level, so ads that are served from the same domain as the content cannot be separated — for example video prerolls on YouTube and promoted posts in X. This is a limitation shared by every DNS-based blocker. Blocking googlevideo.com outright would break video playback entirely.

Privacy

AdBlockAll collects no data of any kind. DNS filtering runs entirely on-device. The only network requests the app makes are to fetch public rule subscriptions. See the privacy policy.

如何开启全网拦截

  1. 打开 AdBlockAll，在「全网拦截」区块点开启。
  2. 允许系统弹窗添加 DNS 配置。
  3. 若首次报权限错误：删除 App → 重新安装 → 重启手机 → 再开一次。这是 iOS 系统层面的问题，不是 App 缺陷。

如何开启 Safari 拦截

  1. 打开 AdBlockAll，在 Safari 区块点如何开启。
  2. 设置 → App → Safari 浏览器 → 扩展 → 内容拦截器。
  3. 打开 AdBlockAll 开关。

这是 iOS 要求的一次性手动步骤，任何 App 都无法代劳。

为什么拦截统计一直是 0

  • Safari 拦截不计入统计：它由系统完成，App 拿不到次数。Safari 里广告确实被拦了，数字也不会涨。
  • 只有全网拦截的命中才计数。开启后浏览一会儿再看。
  • 仍是 0 的话，进统计页点「运行存储自检」：App Group 必须是「可用」，且列表里有 subscription-domains.txt。文件缺失就回主界面点「更新订阅」。

拦不掉的部分

拦截工作在域名层面，因此与正文同域名的广告无法区分 —— 例如 YouTube 视频前贴片、X 时间线里的推广推文。所有基于 DNS 的拦截工具都有这个边界。把 googlevideo.com 整个加进黑名单会导致视频无法播放。

隐私

AdBlockAll 不收集任何数据，DNS 过滤全程在本机完成，App 只请求公开的第三方规则订阅源。详见隐私政策。
